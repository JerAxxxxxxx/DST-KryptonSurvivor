# 当前设计

人物：DC 超人 / Superman。Mod：Krypton Survivor · 氪星幸存者。武器：拉奥之锋 / Rao's Edge，双刃战斧。

玩法以极强属性和无消耗体验为目标。已实现内容与准确数值以 README 和 mod/modmain.lua 为准。美术以 user-pic 的原图为准，不再使用程序绘图。

白天地表已实现每秒 100 生命与 100 理智恢复。0.5.0 将热视线实现为人物自带技能：无需护目镜、不占装备栏，空手或持斧均可发射，伤害与战斧分别配置。鼠标瞄准后按 R，按键可在本机配置中改为 G、Z 或关闭；没有资源消耗，最短发射间隔为 0.35 秒。

热视线沿直线穿透敌人，直接命中排除玩家、随从、伙伴、驯化生物、墙和建筑；命中的可燃生物可以被点燃，原版火焰可能继续蔓延。特效在运行时引用游戏资源，不新增人物或武器美术。护目镜不再是远程能力的必需装备，可保留为未来外观选择。

0.5.1 仅调整热视线视觉，不改变装备、伤害或消耗规则。瞳孔位置记入 assets/slices.json，构建时生成头部局部坐标；各客户端在动画更新后读取当前头部位置，随动作、镜像和观察视角定位光束。正面双束、侧面单束，背面保留双束但不加眼部光点；原版光束左端对齐眼睛，避免向头后延伸，增加亮芯、光晕与小范围眼部发光。用户于 2026-10-04 完成本地复测，反馈暂无问题，准备发布；未逐项确认的联机和装备专项仍见 docs/playtest.md。

未实现规划：太阳披风护甲、飞行、星核护符复活和氪星能量棒。当前红披风是人物外观，不占装备栏。用户最初提出的氪石削弱和夜间消耗示例，与后续“无弱点、无消耗”的目标有冲突，因此尚未加入。

头像使用同一张正面头部；正、侧、背三方向保持原图五官与发型。静态原图不足以提供全部表情、动作遮挡和帽子造型，新增艺术内容需使用生图工具或用户提供素材；不能用 SVG、Canvas 或程序笔画补画。
