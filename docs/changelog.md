# 变更记录

## 0.6.2 · 2026-10-04（相对工坊 0.5.1，工坊更新待发布）

- 新增人物自带飞行，无需装备、无资源消耗，出生默认开启；V 切换，可在本机配置为 B 或关闭按键，服务器可关闭能力。
- 飞行可跨海面及洞穴内部断层，保留普通墙、树等障碍碰撞；安全陆地或船上才能关闭飞行，骑乘时暂停飞行。
- 新增 Ctrl＋地图右键瞬移，使用原版地图坐标转换，无距离或材料限制；只在当前世界分片内移动，地表与洞穴仍通过入口切换。
- 服务器拒绝地图外、洞穴空洞、被建筑或洞口占据的落点及原生特殊屏障；飞行开启可选海面，关闭时限安全陆地或船上。切换飞行与瞬移前需下坐骑。
- 保留原地图拖动、缩放、关闭和普通右键操作。两项能力均支持服务器关闭，操作可在本机配置中关闭。
- 加入三方向悬浮待机与飞行移动动画，使用用户提供的飞行原画；原有人物、头像与战斧美术保留。
- 飞行循环暂不显示手持物品和帽子；攻击、采集及热视线恢复普通人物动作与装备显示，装备属性仍然生效。
- 修复关闭地图后受自动暂停或界面焦点影响而误报“现在无法使用这项能力”的问题；瞬移等待游戏恢复后执行，保留点击时的落点。
- 瞬移成功后增加中英文确认提示；失败区分落点受阻、不安全或受限制，以及暂停、忙碌、骑乘和控制禁用等原因。
- 请求执行前重新检查人物和操作状态，避免死亡、角色变化或重新打开菜单后误触发瞬移。

跨海飞行与地图瞬移已进行游戏测试；洞穴与联机同步仍需进一步验证。本条整合未发布的 0.6.0、0.6.1 开发改动及 0.6.2 成功提示，覆盖工坊 0.5.1 之后的完整更新。

## 0.5.1 · 2026-10-04（已发布至 Steam 创意工坊）

- 修复热视线从头后方发出的视觉问题。
- 根据原图瞳孔位置生成眼部定位数据，各客户端在动画更新后跟随当前头部位置和镜像；正面双束、侧面单束，背面不显示眼部光点。
- 校准原版光束实际边界，让光束从眼睛向前延伸；加强亮芯与光晕，正侧面增加小范围眼部发光。
- 新增热视线连续动画和逐帧几何定位预览，使用编译人物与本机游戏特效像素。
- 保留人物与战斧原图像素、装备规则及伤害配置；光束与眼部亮光资源从已安装游戏加载。

## 0.5.0 · 2026-10-03

- 新增人物自带热视线，无需独立装备；鼠标瞄准后按 R，支持本机配置 G、Z 或关闭，空手与持斧均可使用。
- 直线穿透攻击，射程 20、半宽 0.8，并计入目标体型；伤害独立配置为 2000、10000、50000，默认 2000。
- 无资源消耗，最短发射间隔 0.35 秒；忙碌、工作、死亡、幽灵、暂停、聊天、界面操作或建筑放置期间不触发。
- 直接命中排除玩家、随从、伙伴、驯化生物、墙和建筑；命中后点燃仍存活的可燃、非火焰免疫生物，使用原版火焰蔓延机制。
- 激光特效在运行时引用游戏资源；保留人物、战斧美术与存档 prefab 标识。

## 0.4.2 · 2026-10-02

- 白天地表每秒自动恢复 100 生命，与每秒 100 理智恢复一起运行。
- 满血时停止回血；死亡、幽灵、黄昏、夜晚及洞穴不触发恢复。
- 为项目代码和文档添加 MIT 许可证；图片与衍生贴图保留独立来源说明。

## 0.4.1 · 2026-10-02

- 使用高分辨率人物原图重新划定头部、躯干和四肢选区。
- 躯干不再保留跑步图中的固定腿；移动袖子排除身后红披风的像素。
- 关节坐标替代统一居中画布，修正头、身体和握持的位置；重建头像。
- 补充三方向连续站立、跑步、攻击 GIF 和攻击逐帧预览。
- 武器改为引用游戏自带 cane 动作；自制资源包不再复制原版 anim.bin。
- 提供依赖锁定、可配置的游戏路径和资源构建说明，保留玩法逻辑与 prefab 名称。
